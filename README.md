# Places in My City — Lesson 9

Ingliz tili so‘zlarini Duolingo uslubida o‘rganish uchun bitta sahifali ilova (40 so‘z).
Mashqlar: yangi so‘z, tinglash, tarjimani tanlash, gapni to‘ldirish, juftlash, yozish, gapirish.

## Ishga tushirish

Hech qanday build kerak emas — `index.html` ni brauzerda oching.

## Deploy (Vercel)

1. Repozitoriyni GitHub'ga push qiling.
2. [vercel.com/new](https://vercel.com/new) da repozitoriyni import qiling.
3. Framework Preset: **Other**, build command bo‘sh, output: `./`.
4. Deploy.

## Texnologiya

- Vanilla HTML/CSS/JS, tashqi kutubxonalarsiz
- Progress `localStorage` da saqlanadi
- Talaffuz: Web Speech API (`speechSynthesis`, en-GB)
